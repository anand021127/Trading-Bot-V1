# Strategy V8-D Historical Option Data Requirements Specification

## 1. Executive Summary of Requirements
- **Strategy Identifier:** Strategy V8-D (Fixed -20% Option Stop, +15% Target, ATM Strike Selection)
- **Underlyings Required (2):** `NIFTY50`, `BANKNIFTY`
- **Historical Date Range:** `2024-01-01` to `2024-11-06` (Trading days only, 09:15 to 15:30 IST)
- **Total Unique Historical Expiries Required (90):** 45 NIFTY50 weekly expiries + 45 BANKNIFTY weekly expiries
- **Total Unique Option Strikes Required (160):** 79 NIFTY50 strikes (21,300 to 26,200) + 81 BANKNIFTY strikes (44,600 to 54,200)
- **Option Types:** Both Calls (`CE`) and Puts (`PE`)
- **Total Unique Historical Option Contracts:** **465 contracts** (223 NIFTY50 contracts + 242 BANKNIFTY contracts)
- **Required Candle Resolution:** **1-minute OHLCV** (recommended for intrabar stop/target execution precision) or **5-minute OHLCV** (matching signal timeframe)
- **Volume Data:** **MANDATORY** (Used for volume/liquidity validation and realistic slippage modeling)
- **Open Interest (OI) Data:** **OPTIONAL / RECOMMENDED**
- **Expected Data Directory:** `real_data/options_cache/`

## 2. Exact Schema Expected by OptionsDataLayer

The repository's `backend.backtest.options_data_layer.HistoricalOptionsDataLoader` automatically loads files placed inside `real_data/options_cache/` matching either the Single-Contract format or Array format.

```json
{
  "contract": {
    "underlying": "NIFTY50",
    "expiry": "2024-07-04",
    "strike": 24050.0,
    "option_type": "CE",
    "instrument_key": "NSE_FO|NIFTY2470424050CE",
    "lot_size": 25
  },
  "candles": [
    {
      "timestamp": "2024-07-01T09:15:00+05:30",
      "open": 120.5,
      "high": 125.0,
      "low": 118.0,
      "close": 122.3,
      "volume": 145000,
      "oi": 850000
    }
  ]
}
```

### Field Definitions:
| Field | Type | Description | Required |
| :--- | :--- | :--- | :---: |
| `timestamp` | ISO-8601 String | Candle start time (e.g. `2024-07-01T09:15:00+05:30`) | **YES** |
| `open` | Float | Opening price of the option premium in INR | **YES** |
| `high` | Float | High price of the option premium in INR | **YES** |
| `low` | Float | Low price of the option premium in INR | **YES** |
| `close` | Float | Closing price of the option premium in INR | **YES** |
| `volume` | Float / Int | Traded volume during the bar interval | **YES** |
| `oi` | Float / Int / Null | Open interest at bar close | OPTIONAL |

## 3. Code Readiness & OptionsDataLayer Integration
1. **Can OptionsDataLayer consume real historical option OHLC without code changes?**
   - **YES.** `HistoricalOptionsDataLoader` in `backend/backtest/options_data_layer.py` already includes `load_from_directory()` and O(1) indexed lookup tables mapping `(contract_key, timestamp) -> HistoricalOptionRecord`.
2. **Code changes required to replace Black-76 simulated premiums:**
   - None in the strategy logic (`V8DStrategy`). In the backtest runner, passing `options_data_loader=loader` automatically switches `BacktestEngine` into strict real historical options execution mode.
3. **Backtest behavior when historical option data is missing:**
   - When real option data is missing for any bar or contract, `OptionsDataLayer` strictly returns `None`. `BacktestEngine` records the signal under `DATA_UNAVAILABLE` and skips the trade completely, preventing synthetic price fallbacks or spot price substitutions.
